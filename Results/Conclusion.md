# Conclusion

This project successfully demonstrated the use of the Hadoop ecosystem for large-scale network traffic analysis.

The implementation combined:

- Hadoop Distributed File System (HDFS)
- MapReduce
- Apache Hive

to process and analyze network traffic logs.

The project illustrates how distributed computing technologies can efficiently handle large datasets while providing meaningful security insights through SQL-based analysis.

Overall, the project strengthened practical understanding of distributed storage, parallel processing, and network security analytics.
