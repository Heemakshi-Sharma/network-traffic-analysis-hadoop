# Challenges Faced

During the implementation of this project, several challenges were encountered.

## Challenges

- Setting up the Hadoop environment
- Configuring Hadoop Distributed File System (HDFS)
- Managing large datasets
- Executing distributed MapReduce jobs
- Importing processed data into Hive
- Writing SQL queries for data analysis
- Understanding distributed computing concepts

Each challenge provided valuable practical experience in working with Big Data technologies.
