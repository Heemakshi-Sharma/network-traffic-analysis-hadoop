# Installation Guide

## Prerequisites

Before running this project, install the following software:

- Ubuntu Linux
- Java JDK
- Hadoop
- Apache Hive

## Dataset

Download the KDD Cup 1999 dataset from Kaggle.

Place the dataset inside the local Hadoop environment before uploading it to HDFS.

## Hadoop Services

Ensure Hadoop services are started successfully before beginning the implementation.

## Project Flow

1. Upload dataset to HDFS.
2. Execute MapReduce processing.
3. Store processed output.
4. Load output into Hive.
5. Execute analytical queries.
6. Review generated results.
