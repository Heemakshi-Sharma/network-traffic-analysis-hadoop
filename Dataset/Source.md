# Dataset Source

## Dataset Name

KDD Cup 1999 Network Intrusion Detection Dataset

## Source

The dataset used in this project was obtained from Kaggle.

Dataset Link:
https://www.kaggle.com/datasets/galaxyh/kdd-cup-1999-data

## Description

The KDD Cup 1999 dataset is a benchmark dataset widely used for network intrusion detection and network traffic analysis research.

It contains network connection records classified as either normal traffic or different categories of cyber attacks.

Each record includes multiple network traffic features such as:

- Duration
- Protocol Type
- Service
- Connection Flag
- Source Bytes
- Destination Bytes
- Number of Failed Logins
- Logged-in Status
- Host Statistics
- Attack Label

## Purpose in this Project

The dataset was processed using:

- Hadoop Distributed File System (HDFS)
- MapReduce
- Apache Hive

to analyze network traffic patterns and generate security insights.
