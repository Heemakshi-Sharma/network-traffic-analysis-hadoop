# MapReduce Output

## Output Description

After successful execution of the MapReduce job, the processed network traffic data is stored inside HDFS.

This processed data forms the input for Apache Hive.


## Output Characteristics

- Structured data
- Distributed processing
- Optimized for Hive queries
- Suitable for large-scale network traffic analysis


## Verification

Successful execution is verified by:

- Completion of the Hadoop job
- Output directory creation
- Availability of processed files inside HDFS
