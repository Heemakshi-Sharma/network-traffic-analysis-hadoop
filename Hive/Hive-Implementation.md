# Apache Hive Implementation

## Objective

Apache Hive was used to perform SQL-based analysis on the processed network traffic dataset generated using Hadoop MapReduce.

Hive provides a data warehouse layer on top of Hadoop, allowing large datasets stored in HDFS to be queried using SQL-like syntax.
