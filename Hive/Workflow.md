# Hive Workflow

```
Processed Output
        │
        ▼
Load into Hive
        │
        ▼
Create Database
        │
        ▼
Create Table
        │
        ▼
Import Data
        │
        ▼
Execute SQL Queries
        │
        ▼
Generate Reports
```

## Workflow Description

1. Start the Hive shell.
2. Create the Hive database.
3. Create the required table.
4. Load the processed dataset.
5. Execute SQL queries.
6. Analyze the results.
7. Generate the final report.
