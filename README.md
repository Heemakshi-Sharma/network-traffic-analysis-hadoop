# Network Traffic Analysis using Hadoop, MapReduce & Hive

## Project Overview

This repository contains my M.Tech Cloud Computing project completed at **BITS Pilani**.

The objective of the project was to analyze large-scale network traffic logs using the Hadoop ecosystem and generate security insights through distributed processing.

The project demonstrates the complete workflow of:

- Linux Environment Setup
- Hadoop Distributed File System (HDFS)
- Data Processing using MapReduce
- Data Analysis using Apache Hive
- Network Traffic Analysis
- Cybersecurity Event Reporting

The implementation follows a structured pipeline beginning with raw network log ingestion, distributed processing, Hive-based querying, and generation of analytical reports.

## Business Scenario

Enterprise networks generate millions of log entries every day.

Manual analysis of these logs becomes inefficient due to the volume of data.

This project demonstrates how Big Data technologies can process large network datasets efficiently to identify malicious traffic patterns, attack types, protocol usage, and security threats using distributed computing techniques.

## Project Outcomes

The project successfully demonstrated:

- Distributed storage using HDFS
- Parallel data processing using MapReduce
- SQL-like analytics using Hive
- Network traffic pattern identification
- Detection of malicious network activity
- Performance of distributed analytics on network log data

## Key Findings

- ICMP-based Smurf attacks represented the largest portion of malicious traffic.
- TCP-based Neptune attacks were identified as another major threat.
- Hive queries enabled protocol-wise and service-wise analysis of network events.
- The project demonstrated how distributed data processing can support network security investigations.
